Facilities and services

After the site analysis: decide which facilities and services the local plan holds. Let the toolkit work out what the population needs (LUSPA 2025 standards and the sizes from your local plans), or tick them yourself with the number, the site size and, if you wish, the location (a point, where a site of that size is shaped, or the exact outline). Located sites are kept clear when the roads are designed. River buffers are set under Stream / drainage.

Roads

Edit the roads with the editing ribbon at the top of the map, as in ArcGIS Pro: Select, Create road (width templates), Offset, Extend, Trim, Split, Square ends, Attributes, Delete, Undo / Redo (Ctrl+Z / Ctrl+Y) and Snapping. Each tool opens a panel: select roads, set the options, check the preview, Apply.

Design the roads for me
Pattern Block depth Block length Plot size (ft) x Local roads Collectors Parcels up to

Plot size: breadth (frontage) x length (depth) for the whole planning area. Empty = the LUSPA standard (65-80 x 100 ft). When set, the block depth (2 x length) and block length (whole plots) follow, and every design run cuts the plots to this size. For single blocks after the design use Plot size on the ribbon.

Replaces the current roads with a new design (existing roads and stream / steep reserves are kept). The result loads here for editing.

Suggest a redesign

Draw the area to redesign, choose how, then Redesign. Roads outside the area and roads you drew or edited yourself are kept; the rest of the area is laid out again and joined to the kept roads. Pattern and block settings come from "Design the roads for me" above.

Fast route: OSM outlines where they exist, database outlines (Google, Microsoft) where OSM has none, occupancy and height for every building, walls and fences from the image.
